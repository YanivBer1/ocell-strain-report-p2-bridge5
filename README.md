# דוח מדי עיבור — כלונס P2, גשר 5

[פתיחת הדוח באתר](https://yanivber1.github.io/ocell-strain-report-p2-bridge5/) · [הורדת הדוח כ־PDF](https://yanivber1.github.io/ocell-strain-report-p2-bridge5/O-cell-P2-Bridge5-revised-report.pdf)

מהדורה מתוקנת — 3 באוקטובר 2026. הדוח כולל שני גרפי פרופיל משולבים עם כל 19 שלבי הבדיקה בצבעים נפרדים, כולל שלבי הפריקה. צירי העומק, העיבור והכוח מתחילים באפס. גרף העיבור מול העומס כולל כעת גם את ענף הפריקה.

המדידות, הנוסחאות, טבלאות התוצאות ונספח החישובים נשמרו. לא נוספו נקודות מדידה בראש הכלונס ולא חוברו קווים דרך תא O-cell. כל 133 שורות תוצאות השלבים וכל 95 שורות העברת העומס אומתו מול קובצי ה־CSV שסופקו.

`index.html` הוא הדוח האינטראקטיבי. שלושת קובצי ה־CSV נמצאים לצדו, והורדותיהם מוטמעות גם בדוח לשימוש לא מקוון. ארבעת קובצי SVG כוללים גרפים וקטוריים עם מקרא.

הדוח אינו קובע תסבולת מותרת לכלונס או עקומת שקיעה. הסייגים והנחות החישוב מפורטים בדוח עצמו.

תיקון תצוגת מובייל: כל הגרפים מותאמים לרוחב המסך ללא גלילה אופקית, כך ששני צירי האפס וכל נקודות המדידה נשארים גלויים. נבדקו רוחבי מסך 320–1440 פיקסלים.

גרף פרופיל הכוח שליד בורר השלבים נפתח כעת עם כל 19 השלבים יחד. הבורר מאפשר להציג את כל השלבים או שלב יחיד; המקרא המקומי מאפשר לבחור כל שילוב של שלבים ולהשוות העמסה ופריקה על אותם צירים.
