# דוח מדי עיבור — כלונס P2, גשר 5

האתר מציג את ניתוח מדי העיבור של בדיקת O-cell, כולל גרפים, בחירת שלבי העמסה, מיפוי מלא של החישובים וקובצי תוצאות להורדה.

הקובץ `index.html` הוא עותק זהה של `ocell_strain_report.html` המקומי. שלושת קובצי ה-CSV נמצאים לצדו כדי שקישורי ההורדה בדוח יעבדו גם באתר.

הדוח אינו קובע תסבולת מותרת לכלונס או עקומת שקיעה. הסייגים והנחות החישוב מפורטים בדוח עצמו.
